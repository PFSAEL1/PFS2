PFS SPRAY BOOTHS — COMPLETE ASSET PACKAGE
==========================================
All assets in this folder are hosted on the Manus CDN and referenced by the
production website. The designer does NOT need to re-upload these — they load
automatically from the CDN when the site is deployed.

This folder is provided so the designer has every raw file for archival,
re-hosting on their own CDN, or future use.

DEPLOYMENT NOTE
---------------
The production website ZIP (pfs-spray-booths-PRODUCTION.zip) references all
assets via /manus-storage/... CDN URLs. These URLs are permanent.
If re-hosting assets on a custom CDN, update the asset URLs in the JS bundle.
